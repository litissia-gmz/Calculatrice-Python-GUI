#  Calculatrice Graphique Python

Une application de calculatrice simple et fonctionnelle développée avec **Tkinter**. Ce projet illustre la gestion des interfaces graphiques (GUI) et le traitement des événements utilisateur.

##  Points clés
- Interface graphique intuitive.
- Gestion des erreurs de calcul (ex: division par zéro).
- Code structuré et commenté.
